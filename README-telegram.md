# Приём заявок в Telegram — настройка (один раз, ~10 минут)

Сайт статический (GitHub Pages) и сам принимать формы не умеет. Чтобы
заявки приходили в Telegram и при этом **токен бота не светился в коде
сайта** (как у крупных компаний), используется маленький бесплатный
посредник — Cloudflare Worker. Браузер шлёт заявку воркеру, а воркер уже
пишет в ваш Telegram.

```
Форма на сайте  →  Cloudflare Worker (хранит токен)  →  ваш Telegram
```

## Шаг 1. Создать бота и узнать chat_id

1. В Telegram напишите **@BotFather** → `/newbot` → задайте имя.
   Он пришлёт **токен** вида `1234567890:AA...` — это `BOT_TOKEN`.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой **chat_id**: напишите боту **@userinfobot** — он пришлёт
   ваш `Id` (число). Это `CHAT_ID`.
   *Чтобы заявки падали в общий чат менеджеров — добавьте бота в группу
   и возьмите id группы (обычно с минусом).*

## Шаг 2. Развернуть воркер

1. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатно).
2. **Workers & Pages → Create → Create Worker** → задайте имя
   (например `vluchemdome-lead`) → **Deploy**.
3. **Edit code** → удалите шаблон, вставьте содержимое файла
   [`telegram-worker.js`](telegram-worker.js) из этого репозитория →
   **Deploy**.
4. **Settings → Variables and Secrets → Add** — добавьте три секрета
   (тип *Secret*):
   - `BOT_TOKEN` — токен из шага 1
   - `CHAT_ID` — ваш id из шага 1
   - `ALLOW_ORIGIN` — адрес сайта, например `https://username.github.io`
     (можно временно `*` для проверки)
5. Скопируйте адрес воркера — вида
   `https://vluchemdome-lead.<ваш>.workers.dev`.

## Шаг 3. Подключить сайт

Откройте [`config.js`](config.js) и вставьте адрес воркера:

```js
leadEndpoint: 'https://vluchemdome-lead.ВАШ.workers.dev',
```

Там же замените ник Telegram и, при желании, телефон/WhatsApp.
Также замените `REPLACE_WITH_YOUR_NICK` в ссылках «Написать в Telegram»
на страницах (поиском по проекту).

Готово. Отправьте тестовую заявку — сообщение придёт в Telegram.

## Пока воркер не подключён

Форма честно покажет «Форма пока настраивается, позвоните нам» и **не**
будет делать вид, что заявка ушла. Никакие данные никуда не утекают.

## Защита от спама

- В форме есть скрытое поле-ловушка (honeypot) — боты его заполняют,
  воркер такие заявки тихо игнорирует.
- `ALLOW_ORIGIN` ограничивает приём заявок только с вашего домена.
- Токен бота хранится в секретах воркера, в коде сайта его нет.

## Аналитика (необязательно)

В `<head>` каждой страницы есть закомментированная строка со счётчиком
Яндекс.Метрики. Создайте счётчик, впишите номер в
`window.YM_COUNTER` и раскомментируйте — события форм, кликов по
телефону/мессенджерам и выбора сценария начнут отправляться как цели
(`lead_submit`, `phone_click`, `messenger_click`, `scenario_select`).
